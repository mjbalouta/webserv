Team Member 1 — Network & Request + Partial Routing

Tasks:

Socket / Network Management → handling connections, reading requests

Partial Routing → deciding which server block handles the request

Why important:

They learn how clients connect to the server (networking basics).

They also see how HTTP requests are interpreted in the context of server configuration.

Deliverables:

Accept connections, read raw requests

Parse requests into Request objects

Identify the correct server block (but not full response generation yet)




Team Member 2 — Routing & Response + Partial File Handling

Tasks:

Routing / Location Matching → decide the right location for the request

Response Generation → generate headers and status codes

Partial File Handling → read small static files (like index.html)

Why important:

They work with request-to-response logic, learning HTTP methods, headers, and status codes.

File reading introduces the real-world aspect of serving content.

Deliverables:

Match request path to location

Build Response objects with headers and status codes

Serve simple static files and handle basic GET responses




Team Member 3 — Advanced File / Error Handling + Orchestration

Tasks:

Advanced File / Resource Management → larger files, directory handling, index files

Error Handling → 404, 405, 500, and custom error pages

Server Loop / Orchestration → integrating everyone’s modules, sending responses

Why important:

They learn about real-world server robustness: handling missing files, invalid requests.

They see the full request-response flow and orchestrate everything, which is the essence of running a web server.

Deliverables:

Safely read requested files, detect errors

Return proper error pages

Run the server loop that ties Person 1 and Person 2 together

Key Learning Principles

Everyone touches HTTP requests, routing, and responses, even if some only handle parts of it.

Everyone sees network communication, at least indirectly (Person 3 sends responses).

Everyone learns about files and errors, even if responsibilities vary.
